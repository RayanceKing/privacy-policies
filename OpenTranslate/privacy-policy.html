01适用范围与开发者

本隐私政策适用于由独立开发者 RayanceKing（以下简称“我们”）发布的 Open Translate（以下简称“本应用”），包括：

  • 通过 App Store / TestFlight 分发的 iOS 17+ 与 macOS 12+ 原生应用（以 Safari Web Extension 方式工作）；
  • 使用同一套翻译逻辑的 Chrome / Edge / Safari 浏览器扩展，以及 Tampermonkey 用户脚本。

Open Translate 是一个轻量的网页双语翻译工具：只处理文章与主内容中的可读文本块，在原文后就地插入译文。项目以 AGPL 许可开源，源代码可自行审阅。使用本应用无需注册账号，也没有应用内购买。

02我们不会收集的数据

  • 姓名、邮箱、手机号、账号与密码等身份信息；
  • 设备标识符、IDFA / 广告标识符、我们侧的 IP 访问日志；
  • 精确或粗略的地理位置；
  • 通讯录、照片、日历、麦克风、文件等系统权限数据；
  • 浏览历史、访问的网站清单、用户画像或兴趣标签；
  • 支付与账单信息（本应用没有内购与订阅）；
  • 使用时长、点击流、崩溃日志、遥测或任何“统计数据上报”。

本应用不跨网站或跨应用追踪你，也不使用 Cookie 建立用户画像。由于不存在开发者服务器，我们没有任何可供查询、导出或出售的用户数据库。

如何清除：卸载应用 / 移除扩展即可删除全部本地设置与密钥；也可在设置页使用「恢复默认」重置。

04会发送给第三方的数据

只有当你主动触发翻译（包括开启自动翻译、视频双语字幕，或点击「测试连接」）时，以下内容才会从你的设备直接发往你选择的翻译服务商：

数据说明
待翻译文本文章正文中的可读段落，或你选中的文本
字幕文本开启视频双语字幕时，仅当前时间点前后的一小段字幕；不会一次性发送整部视频
测试连接一句固定的英文短句，用于验证 Key 与网络是否可用
AI 翻译附加信息你自定义的提示词模板，以及本次文本命中的术语条目（不会发送整个词库）
鉴权信息你为该引擎填写的 API Key，作为请求凭证发送给该引擎

传输特点：设备与引擎之间直连；没有我们的中转服务器；没有统计数据上报；我们不记录请求日志；请求不与你的账号或身份关联（本应用也没有账号体系）。

请注意：我们不控制第三方引擎如何处理这些文本，各服务商自身的隐私政策适用于这些请求，其保留与记录机制由服务商决定。请勿对高度敏感的机密内容使用在线翻译引擎；如需数据不出自有环境，可选择自建 LibreTranslate 或本地网关。

06敏感信息保护

本应用默认开启「屏蔽敏感信息」：邮箱地址、疑似电话号码、常见 API Token 在离开设备前会被替换为占位符，译文返回后在本地还原。你可以在设置中关闭该选项。

这层保护是基于模式匹配的尽力而为机制，不保证识别所有敏感内容。翻译任何文本前请自行判断；如需最高级别的保护，请使用本地 / 自建引擎。

07翻译缓存

  • 位置：会话级存储（chrome.storage.session / sessionStorage），仅在内存中，不写入磁盘。
  • 内容：只保存译文与 64 位指纹作为键，不保存原文，因此无法从缓存反推出你读过什么。
  • 生命周期：条目最多保留 12 小时、最多 2000 条，超出按写入顺序淘汰；关闭标签页或关闭浏览器即清空，刷新页面仍可命中。
  • 自动失效：更换引擎、语言、AI 提示词、自定义术语、领域词库选择，或内置词库更新，都会得到不同的缓存键，不会误用旧译文。
  • 手动清空：设置页「隐私与安全 → 翻译缓存」显示当前条数并提供「清空缓存」。

08Safari 扩展权限

为了在你正在阅读的网页中就地插入译文，扩展需要「读取与更改网页内容」权限，并由你在 Safari → 设置 → 扩展 中授予网站访问范围。网页内容只在当前页面内被处理，用于识别正文段落与插入译文，不会被我们保存或上传。

你可以随时把网站访问权限改为「询问」或仅指定网站，也可以直接关闭扩展；关闭后本应用不会读取任何网页内容。翻译文本是否发往第三方，仍遵循第 4 节所述规则——仅在你主动翻译时、仅发往你选择的引擎。

09数据保留与删除

我们自身不持有、不保存任何用户数据，因此没有可请求导出或删除的服务器记录。你可以随时自行完成以下操作：

  1. 卸载应用 / 移除扩展 —— 删除全部本地设置、术语与 API Key；
  2. 在系统设置中撤销扩展的网站访问权限；
  3. 在设置页清空翻译缓存、删除已保存的 API Key，或使用「恢复默认」重置配置；
  4. 删除你手动导出的 JSON / CSV 配置文件。

对于你已经发送给第三方引擎的文本，其保留与删除遵循该服务商的隐私政策与其日志机制，我们无法代为删除。若需行使相关权利，请直接联系对应服务商。

10儿童隐私

  • 你填写的 API Key 只保存在本机，由你自行负责保管，请勿在导出配置或反馈问题时外泄；

01Scope & Developer

This privacy policy applies to Open Translate (the "App"), published by the independent developer RayanceKing ("we"), including:

  • The native iOS 17+ and macOS 12+ app distributed through App Store / TestFlight, which works as a Safari Web Extension;
  • The Chrome / Edge / Safari browser extension and the Tampermonkey userscript built from the same translation logic.

Open Translate is a lightweight bilingual web page translation tool: it processes readable text blocks in articles and main content only, inserting translations in place right after the original text. The project is open source under the AGPL license, so its source code can be audited by anyone. No account is required and there are no in-app purchases.

02What We Do Not Collect

  • Name, email address, phone number, account credentials, or other identity information;
  • Device identifiers, IDFA / advertising identifiers, or IP access logs on our side;
  • Precise or approximate location;
  • Contacts, photos, calendar, microphone, files, or other system-permission data;
  • Browsing history, lists of websites visited, user profiles, or interest tags;
  • Payment or billing information (the App has no in-app purchases or subscriptions);
  • Session duration, clickstream, crash logs, telemetry, or any "statistics reporting".

The App does not track you across websites or apps and does not use cookies for profiling. Because there is no developer server, we hold no user database that could be queried, exported, or sold.

How to erase: uninstall the App or remove the extension to delete all local settings and keys; you can also use "Restore Defaults" in the settings page.

04Data Sent To Third Parties

Only when you initiate a translation (including auto-translate, bilingual video subtitles, or tapping "Test Connection") is the following sent directly from your device to the translation provider you selected:

DataDetails
Text to translateReadable paragraphs of an article, or text you selected
Subtitle textWith bilingual subtitles enabled, only a short window of subtitles around the current playback position; a whole video is never sent at once
Test connectionOne fixed short English sentence used to verify the key and connectivity
AI translation extrasYour custom prompt template and glossary terms matched in that text (the entire glossary is never sent)
AuthenticationThe API key you entered for that engine, sent as a request credential to that engine

How it travels: a direct connection from your device to the engine; no relay server of ours; no analytics reporting; no request logs kept by us; and no association with any account or identity (the App has no account system).

Please note: we do not control how third-party engines handle this text. Each provider's own privacy policy applies to those requests, including its retention and logging practices. Do not use online translation engines for highly sensitive confidential content. Choose a self-hosted LibreTranslate instance or a local gateway if the data must stay in your own environment.

With compatible gateways (one-api, OpenRouter, local Ollama, etc.), data goes to the gateway address you configured — please review that gateway's privacy practices yourself.

06Sensitive Information

"Mask sensitive information" is enabled by default: email addresses, probable phone numbers, and common API tokens are replaced with placeholders before leaving the device and restored locally when the translation returns. You can turn this off in settings.

This is a best-effort pattern-matching mechanism and cannot guarantee detection of every sensitive value. Please use your own judgment before translating any text. For the highest level of protection, use a local or self-hosted engine.

07Translation Cache

  • Where: session storage (chrome.storage.session / sessionStorage), in memory only, never written to disk.
  • What: translations only, keyed by a 64-bit fingerprint; source text is never stored, so the cache cannot reveal what you read.
  • Lifetime: entries expire after at most 12 hours, capped at 2,000 entries (oldest first); closing the tab or browser clears them, while a page refresh still hits the cache.
  • Auto-invalidation: changing the engine, languages, AI prompt, custom terms, selected glossaries, or an updated built-in glossary produces a different cache key, so stale translations are never reused.
  • Manual clearing: Settings → Privacy & Security → Translation Cache shows the entry count and offers "Clear cache".

08Safari Extension Permissions

To insert translations into the page you are reading, the extension needs permission to read and modify web content, and you must grant website access in Safari → Settings → Extensions. Page content is processed only within the current page, to identify body paragraphs and insert translations; it is not stored or uploaded by us.

You can change website access to "Ask" or to specific sites, or disable the extension entirely at any time; once disabled, the App reads no web content. Whether text is sent to a third party still follows Section 4 — only when you initiate a translation, and only to the engine you selected.

09Retention & Deletion

We hold and retain no user data, so there are no server-side records to export or delete. You can take the following steps yourself at any time:

  1. Uninstall the App / remove the extension — deletes all local settings, glossaries and API keys;
  2. Revoke the extension's website access in system settings;
  3. Clear the translation cache, delete saved API keys, or use "Restore Defaults" in the settings page;
  4. Delete any JSON / CSV configuration files you exported manually.

Text you have already sent to a third-party engine is subject to that provider's privacy policy and logging practices; we cannot delete it on your behalf. To exercise related rights, please contact the provider directly.

10Children's Privacy

The App is not directed at children under 13, and we do not knowingly solicit or collect personally identifiable information from children. If you believe a child has provided personal information through the App, please contact us using the address below and we will address it promptly.

11Security

  • Local data is isolated by the operating system / browser sandbox and readable only on that device;
  • Translation requests go directly to the chosen provider over HTTPS, with no intermediary;
  • API keys you enter stay on the device and are your responsibility — never expose them in exported configs or support requests;
  • The project is open source under AGPL, so anyone can audit its network behavior.

Keep in mind that any online translation service may log requests under its own policy, and actual security also depends on the provider you choose and your network environment.

12Changes To This Policy

If our data practices change, we will update this page and revise the "Last updated" date at the top. We encourage you to review it periodically; continued use of the App means you are aware of the updated policy. Significant changes will also be noted in the open-source repository's release notes.

13Contact Us

For questions about this policy, our data practices, or your rights, please get in touch. The App is developed and maintained by an individual, and we do our best to respond promptly.
