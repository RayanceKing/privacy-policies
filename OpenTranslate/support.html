01快速开始

  1. 安装应用
    从 App Store（或 TestFlight）安装 Open Translate，支持 iOS 17+ 与 macOS 12+。
  2. 启用 Safari 扩展
    打开「系统设置 / 设置 → Safari → 扩展」，启用 Open Translate，并为需要翻译的网站授予访问权限。建议先允许全部网站确认功能正常，再按需收窄到指定网站。
  3. 开始翻译
    打开任意文章页面，点击页面边缘的悬浮球或按 Alt + T；点悬浮球上方的齿轮进入设置，选择翻译引擎并按需填写自己的 API Key。

常用快捷键：Alt + T 翻译 / 还原，Alt + Shift + T 翻译选中文本，Alt + S 开关视频双语字幕。

02常见问题（FAQ）

打开网页后点击翻译没有任何反应？

请依次确认：① Safari 扩展已启用，且已授予该网站的访问权限；② 网页已完全加载，必要时刷新一次；③ 该域名没有被加入「排除列表」；④ 设置中「自动翻译」的开关状态；⑤ 悬浮球位置是否被页面元素遮挡。若只在某些站点失效，多为站点结构或权限问题，可按下方方式反馈该站点。

提示请求失败、限流，或 API Key 无效？

在设置页对应引擎卡片点击「测试连接」验证密钥与网络。公共的 Google 翻译 / Microsoft 免费通道可能被限流或在某些网络环境下不可达，可稍后重试或切换引擎。使用 DeepL、Azure、OpenAI、DeepSeek、Gemini、Claude 时，请核对密钥、端点类型（DeepL Free / Pro）、区域设置与账户额度。长期使用建议改用自己的正式密钥或自建 LibreTranslate。

译文没出现，或只翻译了一部分页面？

本应用只处理文章与主内容中的可读文本块，不翻译输入框、代码块、预格式化文本、导航栏与按钮，也不翻译自身生成的内容。可切换显示模式（双语对照 / 仅译文 / 悬停显示）确认；复杂站点可在项目 SITE_RULES 中补充选择器，欢迎在 GitHub 提交站点适配建议。

视频双语字幕不显示？

需要视频本身提供字幕轨（浏览器 textTracks、WebVTT，或 YouTube 的字幕接口）。直播、纯音乐、无字幕视频无法生成双语字幕——本应用不做语音识别。请按 Alt + S 或在弹出面板中确认字幕已开启，并检查设置里的字号、距底部距离与是否关闭了「自动加载字幕」。

页面样式错乱，或「仅译文」还原后布局有变化？

「仅译文」模式会临时替换段落 DOM，极端动态页面还原后可能出现轻微样式差异，刷新页面即可恢复；「双语对照」最稳妥。此外，少数启用 Trusted Types 的站点若已占用同名策略，悬浮控件可能受限，请附带站点地址反馈给我们。

如何清空翻译缓存、重置设置或迁移配置？

设置页「隐私与安全 → 翻译缓存」可查看条数并一键清空；「恢复默认」可重置设置；设置页还提供 JSON 配置的导入 / 导出，术语库支持 CSV 导入 / 导出，可用于手动迁移到其他设备。缓存只存译文、不存原文，关闭标签页即自动清空。

我的设置、API Key、术语库会同步到其他设备吗？会上传吗？

不会。所有设置与密钥仅保存在本机，应用没有账号体系，也没有开发者服务器，不会同步到 iCloud 或云端。需要迁移请使用设置页的导入 / 导出功能。请注意：导出的 JSON 配置中可能包含你填写的 API Key，请自行妥善保管。

应用会收集我的浏览记录吗？有广告、内购或账号吗？

不会收集浏览记录。本应用没有账号、没有广告、没有应用内购买、没有任何统计或崩溃上报，也没有中转服务器。翻译请求由设备直接发往你选择的引擎。详见隐私政策。

使用这些翻译引擎需要付费吗？

应用本身免费且开源。但 DeepL、Azure、OpenAI、DeepSeek、Google Gemini、Claude 等引擎可能需要你自己的 API Key，并可能由服务商收取费用；相关账户、额度与账单由你与服务商自行管理，与本应用无关。Google、MyMemory、Microsoft 免费通道等公共端点无需密钥，但没有服务等级保证。

macOS 上扩展不生效，或网络请求被拦截？

确认扩展已在 Safari 扩展设置中启用，且网站访问范围包含目标站点。macOS 版本启用沙盒与 Hardened Runtime，网络权限已在工程中开启；若处于企业网络、代理或内容过滤环境，请检查是否拦截了对翻译服务端点的请求。可换用「测试连接」快速定位。

想自行构建、提功能建议或报告 Bug？

项目以 AGPL 许可开源，仓库内包含 Swift 原生工程、浏览器扩展与用户脚本。欢迎在 GitHub Issues 提交问题或建议，也欢迎发起 Pull Request。

01Getting Started

  1. Install the app
    Install Open Translate from the App Store (or TestFlight). Requires iOS 17+ or macOS 12+.
  2. Enable the Safari extension
    Go to System Settings / Settings → Safari → Extensions, enable Open Translate, and grant website access for the sites you want to translate. Start with access to all websites to confirm everything works, then narrow it down to specific sites if you prefer.
  3. Start translating
    Open any article page and tap the floating button at the screen edge, or press Alt + T. Tap the gear above the floating button to open settings, choose a translation engine, and enter your own API key if required.

Shortcuts: Alt + T translate / restore, Alt + Shift + T translate selected text, Alt + S toggle bilingual video subtitles.

02Frequently Asked Questions

Nothing happens when I tap translate on a page?

Check in order: ① the Safari extension is enabled and has access to that website; ② the page finished loading (refresh if needed); ③ the domain is not in your exclusion list; ④ the "auto-translate" setting; ⑤ the floating button is not covered by page elements. If it only fails on certain sites, it is usually a site-structure or permission issue — please send us the site address.

Requests fail, get rate-limited, or my API key is rejected?

Use "Test Connection" on the engine card in settings to verify the key and connectivity. The public Google Translate / Microsoft free channels may be rate-limited or unreachable on some networks — retry later or switch engines. For DeepL, Azure, OpenAI, DeepSeek, Gemini or Claude, double-check the key, endpoint type (DeepL Free / Pro), region settings and account quota. For long-term use, a formal key of your own or a self-hosted LibreTranslate instance is recommended.

Translations are missing or only part of the page is translated?

The app only processes readable text blocks in articles and main content. It does not translate input fields, code blocks, preformatted text, navigation bars, buttons, or content it generated itself. Try a different display mode (bilingual / translation only / hover). For complex sites, selectors can be added to SITE_RULES in the project — site compatibility suggestions are welcome on GitHub.

Bilingual video subtitles do not appear?

The video must provide caption tracks (browser textTracks, WebVTT, or YouTube's caption interface). Livestreams, music-only videos and videos without captions cannot be subtitled — the app performs no speech recognition. Press Alt + S or use the popup to confirm subtitles are enabled, and check font size, bottom offset and whether "auto-load subtitles" was turned off in settings.

The page layout breaks, or looks slightly different after "translation only" is restored?

"Translation only" temporarily replaces paragraph DOM nodes; highly dynamic pages may show minor style differences after restoring, which a refresh fixes. Bilingual mode is the safest option. On a few sites using Trusted Types, if a policy with the same name is already taken, the floating controls may be limited — please report the site address to us.

How do I clear the translation cache, reset settings, or move my configuration?

Settings → Privacy & Security → Translation Cache shows the entry count and offers a one-tap clear. "Restore Defaults" resets settings. Settings also supports JSON config import / export, and the glossary supports CSV import / export for manual migration to another device. The cache stores translations only, never source text, and clears automatically when the tab is closed.

Are my settings, API keys and glossaries synced or uploaded to other devices?

No. All settings and keys stay on the device. There is no account system and no developer server, and nothing syncs to iCloud or the cloud. Use the import / export feature if you need to migrate. Note that an exported JSON configuration may contain API keys you entered — keep that file safe.

Does the app collect my browsing history? Are there ads, purchases or accounts?

It does not collect browsing history. There are no accounts, no ads, no in-app purchases, no analytics or crash reporting, and no relay server. Translation requests go directly from your device to the engine you selected. See the Privacy Policy for details.

Do the translation engines cost money?

The app itself is free and open source. Engines such as DeepL, Azure, OpenAI, DeepSeek, Google Gemini and Claude may require your own API key and may be billed by the provider; accounts, quotas and billing are managed between you and that provider, independent of this app. Public endpoints such as Google, MyMemory and the Microsoft free channel need no key but come with no service-level guarantee.

The extension does not work on macOS, or network requests are blocked?

Make sure the extension is enabled in Safari's extension settings and that website access covers the target site. The macOS build uses the sandbox and Hardened Runtime with network entitlement enabled. On corporate networks, proxies or content filters, check whether requests to translation endpoints are being blocked. "Test Connection" is a quick way to isolate this.

Can I build it myself, suggest a feature, or report a bug?

The project is open source under the AGPL license and includes the Swift native project, the browser extension and the userscript. Please open an issue or suggestion in GitHub Issues; pull requests are welcome too.
