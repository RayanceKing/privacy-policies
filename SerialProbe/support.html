01快速开始

  1. 选择串口设备
    安装并打开串口通，在设备列表中选择已连接的串口。
  2. 设置通信参数
    将波特率、数据位、停止位与校验位设置为与发送端完全一致，并确认编码格式（ASCII / Hex）。
  3. 开始收发数据
    打开连接后即可发送与查看数据；若出现异常，请按下方常见问题排查。

02常见问题

软件无法识别串口设备？

请确认驱动程序（如 CH340、CP210x、PL2303）已正确安装。同时检查物理连接线是否松动，或尝试更换电脑 USB 接口。

接收到的数据是乱码？

请核对波特率、数据位、停止位和校验位是否与您的发送端设备完全一致。此外，请检查编码格式（ASCII / Hex）是否正确切换。

显示「串口被占用」？

请确保没有其他串口调试工具、IDE 终端或后台服务正在占用该 COM 端口。关闭占用程序后重新打开连接即可。

01Getting Started

  1. Select a serial device
    Install and open Serial Probe, then choose the connected serial port from the device list.
  2. Configure communication parameters
    Match the baud rate, data bits, stop bits and parity exactly with the sending device, and confirm the encoding format (ASCII / Hex).
  3. Start sending and receiving
    Open the connection to send and view data. If something goes wrong, check the FAQ below.

02Frequently Asked Questions

The app cannot detect the serial device?

Make sure the driver (for example CH340, CP210x or PL2303) is installed correctly. Check the physical cable connection, or try a different USB port on the computer.

Received data looks garbled?

Verify that the baud rate, data bits, stop bits and parity exactly match the sending device. Also check that the encoding format (ASCII / Hex) is switched correctly.

It says the serial port is already in use?

Make sure no other serial debugging tool, IDE terminal or background service is occupying that COM port. Close the conflicting program and open the connection again.
